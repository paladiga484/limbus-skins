# limbus-skins 1.0.2

- **Dashes:** an identity runs up to the enemy in one drawn pose. Callisto and Valencina have
  no such drawing in the game, and the Old G Corp. Head Manager's and L'Inamovible's are
  standing poses, so those skins slid in standing still. They now lunge, using a frame from
  their own attacks.
- **Solemn Lament Yi Sang:** the butterfly head stays upright in the two frames where he bows.
- Built skins are rebuilt automatically on the next `apply`.

Install: download the `.whl`, then `pip install --user limbus_skins-1.0.2-py3-none-any.whl`.
Check the download with `sha256sum -c SHA256SUMS`.

Private servers only. Helper skins have been seen working in fights; repaints build and pass
every check but are new, so report anything that looks off.
